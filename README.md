# Linux SSH Brute-Force Defense Lab

This project simulates a controlled SSH brute-force attack and demonstrates how a Linux system detects and mitigates unauthorized login attempts.

## Key Technologies

* Debian Linux
* OpenSSH
* Fail2ban
* UFW Firewall
* Kali Linux (attack simulation)

## What This Project Shows

* SSH authentication security
* Real-time system logging
* Intrusion detection and prevention
* Automated IP banning
* Firewall-based protection

## Outcome

The system successfully detected and blocked brute-force login attempts without manual intervention.
